# LaTeXShot release record

LaTeXShot v1.0.0 ships the desktop-tested Pix2Text model and Equation
History. The user approved manual publication of the verified offline
installer. See the [release notes](.github/release-notes/v1.0.0.md),
[benchmark](benchmarks/pix2text-v1/README.md), and
[package verification](docs/releases/v1.0.0-package.md).

The archived Plus-S decoder findings are in the
[recognition diagnosis](benchmarks/plus-s-screen/diagnosis/README.md).
The older live crop-control manifest uses a relative source path in this
public snapshot. Its crop bytes and individual image hashes are preserved.
