# v1.0.0 offline package rehearsal

Built the integrated Apple silicon app in local package mode with the locked
Pix2Text runtime and eight model files. The app bundle declares v1.0.0 and
selects Pix2Text through its signed Info.plist. The packaged model lock
matches the source. App and Sparkle signatures passed deep, strict
verification. The DMG checksum and ZIP integrity checks passed.

Mounted the DMG read-only at a new temporary path and verified the copied
app signature, arm64 executable, and Applications link. Ran the worker
directly from the mounted bundle with an empty home directory and sandbox
rules denying the network, Homebrew, the trial environment and model cache,
and the original build assets. A loopback canary confirmed network denial.
The worker returned the exact recorded Pix2Text response for frozen crop
`small-type-02`. The independent runtime relocation covered six frozen
crops and same-worker recovery from a malformed input.

The staged input archives were checksum-verified and extracted with the
release filter. The files are local.

The rehearsal used ad-hoc signing and disabled update checks. Clean-account
installation, Launch at Login, and the packaged production updater require
separate evidence. The [printed benchmark](../../benchmarks/pix2text-v1/README.md)
missed the public accuracy requirement.
